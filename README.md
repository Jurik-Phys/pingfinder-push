
## PingFinder message daemon IPC client

CLI utility for sending notifications and other messages
to PingFinder clients via the PingFinder messaging daemon.

## Build

Create a build directory and configure the project:

~~~bash
mkdir build
cd build
cmake ..
~~~

Build the project:

~~~bash
cmake --build . --paralell
~~~
